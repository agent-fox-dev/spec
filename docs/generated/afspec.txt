package afspec // import "github.com/agent-fox-dev/spec/afspec"

Package afspec is the reference Go library for the agent-fox specification
format, version 3. It loads, validates, mutates, saves and renders spec
packages with byte-for-byte round-trip fidelity. The format is specified in
specification/spec-format-v3.md in this module's repository.

Spec structs are treated as value types — mutation methods such as Transition
and Supersede return new Spec copies rather than modifying the receiver in
place.

# Concurrency

This package provides no goroutine-safety guarantees. Spec instances are not
safe for concurrent use by multiple goroutines. Callers are responsible for
synchronizing concurrent access to Spec instances externally (e.g. using a
sync.Mutex or by confining each Spec to a single goroutine).

FUNCTIONS

func ArchiveDestination(specDir, root string) (string, error)
    ArchiveDestination is where MoveUnderArchive puts the package at specDir:
    <root>/archive/<base name of specDir>. It writes nothing.

    Returns a SaveError when that path already exists (the message is "archive
    conflict: <path> already exists"; a dangling symbolic link counts, since a
    rename would replace it) or when whether it exists cannot be found out.

func ArtifactFileName(step GenerationStep) string
    ArtifactFileName returns the on-disk file name for a step's artifact.

func ComputeExitCode(findings []LintFinding) int
    ComputeExitCode returns 1 if any finding has Severity "error", 0 otherwise.

func ComputeIntentHash(body string) (string, error)
    ComputeIntentHash extracts the ## Intent section from a PRD body string,
    normalizes it, computes its SHA-256 hash, and returns the hex-encoded hash
    string. The hash is stable: identical intent text always produces the same
    hash.

    Returns an IntentError if the body does not contain a ## Intent section or
    if the body is empty.

func DecodeArtifact(step GenerationStep, content map[string]any) (any, error)
    DecodeArtifact turns the tool input a model returned — a decoded JSON object
    — into the typed artifact for the given step.

func EstimateTokens(text string) int
    EstimateTokens estimates the token count of text using the chars/4
    heuristic: len(text) / 4 (integer floor division).

func EvidenceTestsArgument(command string) int
    EvidenceTestsArgument is the index, in the command split as the gate splits
    it, of the one argument that is the placeholder {tests}: -1 when the command
    cannot be split, has no such argument, or holds the placeholder anywhere
    else too.

func FormatValidationEntries(entries []ValidationEntry) string
    FormatValidationEntries renders validation entries as the feedback a
    generation pipeline sends back to the model for repair. Each line names the
    rule so the model can act on it.

func HasIntent(body string) bool
    HasIntent reports whether body carries the intent section ComputeIntentHash
    hashes, by the same rule: a checker that accepted another spelling would
    pass a PRD that activation then refuses.

func IsExtensionKey(key string) bool
    IsExtensionKey reports whether key is an extension key.

func IsSpecDirName(name string) bool
    IsSpecDirName validates whether a directory name matches the NN_snake_case
    pattern (two-or-more-digit numeric prefix, underscore, then one or more
    snake_case segments).

func IsSpecName(s string) bool
    IsSpecName reports whether s is a valid spec name: exactly the part of
    a spec directory name after the numeric prefix, so a name that passes it
    always makes a valid directory.

func ListSpecDirs(root string) ([]string, error)
    ListSpecDirs returns the names of the NN_name directories under root,
    in the order of their numbers: the prefix compared as a number, so that 99_y
    comes before 100_x, and a tie broken by the whole name. It lists directories
    whether or not they hold a package that loads.

func LoadDependentInterfaces(specID string, specRoot string) []map[string]any
    LoadDependentInterfaces loads interface summaries from the upstream specs
    that specID depends on: external API symbols and criterion contracts,
    one map per upstream spec.

    It degrades gracefully: any spec that cannot be discovered or loaded is
    skipped and the remaining ones are still returned. The result is never nil.

func MarshalJSON(v interface{}) ([]byte, error)
    MarshalJSON serializes a spec artifact struct to deterministic JSON. Struct
    fields are serialized in JSON Schema property order and all map[string]T
    keys are sorted alphabetically. The output uses 2-space indentation with a
    trailing newline, so that a spec on disk round-trips through LoadSpec and
    Save byte-for-byte.

func MigrateV2(dir string) error
    MigrateV2 converts the version 2 package in dir to version 3 in place: it
    writes prd.md, requirements.json, tasks.json, progress.json, architecture.md
    when there is one and spec.md, through the temporary files and renames a
    save uses, whatever the package's status, and removes test_spec.json. The
    errors are LoadV2's, and a SaveError when the write or the removal fails.

func MoveToArchive(specDir, root string) error
    MoveToArchive transitions a spec to the archived state and moves the spec
    directory to {root}/archive/ with MoveUnderArchive.

    A spec that is not already archived is transitioned first, a superseded
    one included (superseded to archived is a move the lifecycle allows).
    The destination is looked at before that, so a taken destination leaves the
    spec as it was. Creates the archive directory if it does not exist.

    Returns a SaveError if the archive directory already contains a directory
    with the same name, or the spec cannot be loaded, moved or written.

func MoveUnderArchive(specDir, root string) (string, error)
    MoveUnderArchive moves the package at specDir to ArchiveDestination(specDir,
    root) and returns the new directory. It rewrites no file, so the package's
    status, progress and content stay as they were: the caller writes the status
    first, with Transition or Supersede, and only an archived or a superseded
    package lives under archive/ (format v3 §9).

    It creates <root>/archive/ (mode 0755 before the umask) if it is missing.

    Returns the LoadError when the package does not load, a LifecycleError
    when its status is neither archived nor superseded, and a SaveError when
    the destination is taken or the directory cannot be created or renamed.
    In each case the package is where it was.

func NextCriterionID(r Requirement) string
    NextCriterionID returns the next free criterion ID within a requirement,
    {requirement_id}.{C}.

func NextExecutionPathID(req RequirementsV3Json) string
    NextExecutionPathID returns the next free path ID, PATH-{N}.

func NextRequirementID(req RequirementsV3Json) string
    NextRequirementID returns the next free requirement ID, REQ-{N}.

func NextTaskID(t TasksV3Json) int
    NextTaskID returns the next free task ID. Task IDs are plain integers
    sequential from 1 (Appendix A); on a full package the next free id is the
    integration task's.

func ParseSpecDirName(name string) (string, string, error)
    ParseSpecDirName parses a valid NN_snake_case directory name and returns the
    numeric prefix and the snake_case name portion as separate values.

    Returns an error if the name does not match the NN_snake_case pattern.

func ResolveSpecsDir(flag, root string) string
    ResolveSpecsDir picks the spec root: the flag, then the environment,
    then the repository's own .specs. A relative value is taken against root.

func SchemaNameForStep(step GenerationStep) (string, bool)
    SchemaNameForStep returns the bundled schema that validates the artifact a
    step produces.

func Schemas() map[string][]byte
    Schemas returns the bundled JSON Schema files as a map of schema file
    names to their raw bytes. The schemas are embedded at compile time from
    the schemas/ directory via //go:embed. The returned map is never nil and is
    never empty because schema files are embedded at compile time.

func UnknownFields(raw any, target any) []string
    UnknownFields lists, as JSON pointers (`/tasks/0/done-when`), the keys in
    raw — a decoded JSON value — that the type of target, a pointer to the
    Go value it decodes into, has no field for. Nil when there are none. An
    extension key (IsExtensionKey) is allowed by every schema and is not listed.

func ValidTaskTransition(current, target TaskState) bool
    ValidTaskTransition reports whether current → target is allowed.

func ValidTransition(current, target string) bool
    ValidTransition checks the transition table and returns true if the
    transition from current to target state is allowed, false otherwise. This is
    a pure function with no side effects.

    Allowed transitions:
      - draft -> active
      - draft -> archived
      - active -> sealed
      - sealed -> superseded
      - sealed -> archived
      - superseded -> archived

type BootstrapError struct {
	Msg string
	Err *SpecError
}
    BootstrapError is returned when BootstrapSpec.Finalize fails due to missing
    artifacts or validation errors.

func (e *BootstrapError) Error() string

func (e *BootstrapError) Unwrap() error

type BootstrapSpec struct {
	SpecID       string
	SpecName     string
	Title        string
	CreatedAt    string
	Profile      string
	Requirements *RequirementsV3Json
	Tasks        *TasksV3Json
	PRDBody      string
	Architecture string
}
    BootstrapSpec supports incremental population of spec artifacts with
    deferred cross-file validation. Use NewBootstrapSpec to create one,
    set artifacts on it, then call Finalize to assemble and validate the Spec.

func NewBootstrapSpec(specID, specName string) *BootstrapSpec
    NewBootstrapSpec creates a BootstrapSpec with the given specID and specName.
    All artifact fields start as nil/zero values. Title and CreatedAt default
    to values that satisfy the PRD frontmatter schema and should be overwritten
    with the real ones before Finalize. Profile is "" (full) or ProfileLite.

func (b *BootstrapSpec) Finalize() (*Spec, []ValidationError)
    Finalize checks that all required artifacts (Requirements, Tasks, PRDBody)
    are set, assembles a Spec from them, and runs full schema and cross-file
    validation. Returns (*Spec, nil) on success.

    If any required artifacts are missing, returns (nil, []ValidationError)
    where each missing artifact produces a ValidationError with Rule="bootstrap"
    and Message="Missing artifact: {name}".

    If all artifacts are present but validation fails, returns (nil,
    []ValidationError) with validation error details.

    The BootstrapSpec is not mutated by Finalize; calling it multiple times
    produces independent results.

type Check struct {
	// unit exercises one component with its collaborators stubbed; integration two or
	// more real components; property an invariant over an input domain.
	Kind *CheckKind `json:"kind,omitempty,omitzero" yaml:"kind,omitempty" mapstructure:"kind,omitempty"`

	// Language-agnostic assertions. May name the function, file and existing test the
	// check extends.
	Pseudocode *string `json:"pseudocode,omitempty,omitzero" yaml:"pseudocode,omitempty" mapstructure:"pseudocode,omitempty"`

	// The criterion whose own check verifies this one too, or the path whose smoke
	// check does.
	SameAs *string `json:"same_as,omitempty,omitzero" yaml:"same_as,omitempty" mapstructure:"same_as,omitempty"`

	// The preconditions the criterion's condition does not state.
	Setup []string `json:"setup,omitempty,omitzero" yaml:"setup,omitempty" mapstructure:"setup,omitempty"`
}
    How a criterion is verified: its own check (kind, setup, pseudocode),
    or the same as another criterion's check or a path's smoke check (same_as).

func OwnCheck(kind CheckKind, setup []string, pseudocode string) Check
    OwnCheck is a criterion's own check: its kind, and the setup and the
    pseudocode when they are not empty.

func SameAs(id string) Check
    SameAs is a shared check: the same as the named criterion's own check,
    or the named path's smoke check.

func (ch Check) IsShared() bool
    IsShared reports whether the check is the same as another's.

func (ch Check) KindText() string
    KindText returns the kind of an own check, or "" for a shared one.

func (ch Check) PseudocodeText() string
    PseudocodeText returns the pseudocode, or the empty string when absent.

type CoverageReport struct {
	Covered   []string
	Uncovered []string
}
    CoverageReport lists the criteria whose check resolves and the paths
    that carry a smoke check (Covered), and those that do not (Uncovered),
    in artifact order.

    Format v3 §8.5: coverage is computed, never stored. On a package that

type Criterion struct {
	// Action corresponds to the JSON schema field "action".
	Action string `json:"action" yaml:"action" mapstructure:"action"`

	// Check corresponds to the JSON schema field "check".
	Check Check `json:"check" yaml:"check" mapstructure:"check"`

	// The WHEN / WHILE / IF / WHERE clause. Absent for ubiquitous. A second condition
	// is written into it, joined with and.
	Condition *string `json:"condition,omitempty,omitzero" yaml:"condition,omitempty" mapstructure:"condition,omitempty"`

	// What the caller observes, and what the check asserts. Required for unwanted.
	Contract *string `json:"contract,omitempty,omitzero" yaml:"contract,omitempty" mapstructure:"contract,omitempty"`

	// Id corresponds to the JSON schema field "id".
	Id string `json:"id" yaml:"id" mapstructure:"id"`

	// Pattern corresponds to the JSON schema field "pattern".
	Pattern CriterionPattern `json:"pattern" yaml:"pattern" mapstructure:"pattern"`

	// The acting component. Defaults to the requirement's system, then to "system",
	// when rendering.
	System *string `json:"system,omitempty,omitzero" yaml:"system,omitempty" mapstructure:"system,omitempty"`
}
    One EARS statement with its check. The rendered sentence is derived from
    pattern, condition, system and action.

func EventDrivenCriterion(id, condition, system, action string) Criterion
    EventDrivenCriterion constructs a criterion with the event_driven pattern:
    "WHEN {condition}, THE {system} SHALL {action}".

func GetCriterion(r Requirement, id string) (*Criterion, bool)
    GetCriterion returns a copy of the criterion with the given ID.

func OptionalCriterion(id, condition, system, action string) Criterion
    OptionalCriterion constructs a criterion with the optional pattern: "WHERE
    {condition}, THE {system} SHALL {action}".

func StateDrivenCriterion(id, condition, system, action string) Criterion
    StateDrivenCriterion constructs a criterion with the state_driven pattern:
    "WHILE {condition}, THE {system} SHALL {action}".

func UbiquitousCriterion(id, system, action string) Criterion
    UbiquitousCriterion constructs a criterion with the ubiquitous pattern:
    "THE {system} SHALL {action}". Correctness properties are written this way,
    with an action that starts with "for any …". The check is the caller's to
    set (OwnCheck, SameAs).

func UnwantedCriterion(id, condition, system, action, contract string) Criterion
    UnwantedCriterion constructs a criterion with the unwanted pattern: "IF
    {condition}, THEN THE {system} SHALL {action}". The contract is mandatory
    for this pattern (§6.5.2, rule C6).

func (c Criterion) ConditionText() string
    ConditionText returns the condition clause, or the empty string when absent.

func (c Criterion) ContractText() string
    ContractText returns the contract, or the empty string when absent.

func (c Criterion) RenderEARS() string
    RenderEARS renders the criterion as its EARS sentence followed, when a
    contract is present, by a second line "→ {contract}" (§11.2). A contract the
    coder cannot see does not exist, so every renderer goes through this.

func (c Criterion) RenderEARSSentence() string
    RenderEARSSentence renders the criterion as its EARS sentence (§6.2.1):

      - ubiquitous: "THE {system} SHALL {action}"
      - event_driven: "WHEN {condition}, THE {system} SHALL {action}"
      - state_driven: "WHILE {condition}, THE {system} SHALL {action}"
      - unwanted: "IF {condition}, THEN THE {system} SHALL {action}"
      - optional: "WHERE {condition}, THE {system} SHALL {action}"

    The contract is not part of the sentence; renderers append it on a second
    line as "→ {contract}" (§11.2). Use RenderEARS for both at once. The system
    is the criterion's own; a renderer resolves the requirement's first.

func (c Criterion) SystemName() string
    SystemName returns the acting component the criterion itself names,
    defaulting to "system" when it omits it. A criterion inside a requirement
    takes the requirement's system first: see Requirement.Resolve.

func (c Criterion) WithCheck(kind CheckKind, setup []string, pseudocode string) Criterion
    WithCheck returns a copy of the criterion carrying its own check of the
    given kind, with the setup and the pseudocode when they are not empty
    (format v3 §6.2.2).

func (c Criterion) WithContract(contract string) Criterion
    WithContract returns a copy of the criterion carrying the given contract.
    A contract is required for unwanted criteria and recommended whenever the
    result is consumed by something else.

func (c Criterion) WithSameCheckAs(id string) Criterion
    WithSameCheckAs returns a copy of the criterion whose check is the same as
    the named criterion's own check, or the named path's smoke check.

type Dependency struct {
	// Reason corresponds to the JSON schema field "reason".
	Reason string `json:"reason" yaml:"reason" mapstructure:"reason"`

	// Spec corresponds to the JSON schema field "spec".
	Spec string `json:"spec" yaml:"spec" mapstructure:"spec"`
}

type DependencyEdge struct {
	FromSpec string
	ToSpec   string
	Reason   string
}
    DependencyEdge is a directed edge: FromSpec depends on ToSpec.

type DependencyGraph struct {
	Edges []DependencyEdge
}
    DependencyGraph is the inter-spec dependency graph built from the
    dependencies list of each spec's tasks.json.

func BuildDependencyGraph(metas []SpecMeta, root string) (*DependencyGraph, error)
    BuildDependencyGraph reads tasks.json for each spec in the provided
    SpecMeta slice, extracts cross-spec dependency declarations, and returns a
    DependencyGraph.

    If a tasks.json references a spec ID not present in the provided SpecMeta
    slice, the dangling reference is recorded as an error and returned alongside
    the partial graph.

func (g *DependencyGraph) Dependencies(specID string) []DependencyEdge
    Dependencies returns all edges where the given spec is the dependent (i.e.,
    edges where FromSpec matches specID — the spec's own dependencies).

func (g *DependencyGraph) Dependents(specID string) []DependencyEdge
    Dependents returns all edges where other specs depend on the given spec
    (i.e., edges where ToSpec matches specID).

func (g *DependencyGraph) DependsOn(from, to string) bool
    DependsOn reports whether spec from depends on spec to, directly or through
    other specs.

func (g *DependencyGraph) TopologicalSort() ([]string, error)
    TopologicalSort returns spec IDs in topological order using Kahn's algorithm
    such that every spec appears before its dependents. Returns an error if a
    cycle is detected.

    Nodes are inferred from edges. An empty graph returns an empty slice.

type Handoff struct {
	// The criteria of this package that depend on the handoff being wired.
	Criteria []string `json:"criteria" yaml:"criteria" mapstructure:"criteria"`

	// Id corresponds to the JSON schema field "id".
	Id string `json:"id" yaml:"id" mapstructure:"id"`

	// The spec id of the package that takes the handoff.

	// The extension point or entry point left for the receiving package.

type InboundHandoff struct {
	SenderDir  string
	SenderID   string
	Handoff    Handoff
	Criteria   []string
	Unreadable string
}
    InboundHandoff is a handoff another package of the spec root addresses to
    a package, as a renderer reads it: the sending package's directory and id,
    the handoff, and the sentences of the sender's criteria that depend on it.
    Unreadable says why the sending package could not be read, when it could
    not; the handoff then holds its id alone.

func InboundHandoffs(specsDir string, s *Spec) []InboundHandoff
    InboundHandoffs reads, from the packages under specsDir, every handoff
    addressed to s, in the order of the packages and their handoffs. A package
    a task of s takes a handoff from and that cannot be read is an entry of its
    own, with why, so that a render can say so and go on.

func (in InboundHandoff) Ref() string
    Ref is the handoff as a task of the receiver names it in takes_handoffs.

type LintFinding struct {
	SpecName string
	File     string
	Rule     string
	Severity string // one of "error", "warning", "hint"
	Message  string

}

func SortFindings(findings []LintFinding) []LintFinding
    SortFindings returns a new slice sorted primarily by SpecName ascending,
    then by File ascending, then by Severity in the order error < warning <
    hint. The input slice is not modified.

type LintResult struct {
	Findings []LintFinding

func ChooseNext(specsDir string, display func(string) string) (NextChoice, error)
    ChooseNext chooses the package to implement now among the packages under
    specsDir. They are ordered by the dependencies their tasks.json declare,
    ties broken by number, so that a package comes after every package it
    depends on; the next is the first in that order that is open (draft or

    archive/). display shows a package directory in the reasons and the result;
    nil shows it as it is. A cycle among the packages is a *CycleError, and a
    spec root that cannot be read a *SpecRootError.

type Spec struct {
	// PRD frontmatter fields
	SpecID     string
	SpecName   string
	Title      string
	Status     string
	CreatedAt  string
	Source     string
	Supersedes []string
	IntentHash *string
	// ContractHash is the hash of each contract file recorded at activation,
	// keyed by its file name, or nil for a package activated without one
	// (contract.go).
	ContractHash  map[string]string
	SchemaVersion int
	// Profile is the package's profile, ProfileFull or ProfileLite, or ""
	// when the frontmatter names none, which is full (format v3 §4.1).
	Profile string
	// SteeringVersion is the version of the spec root's steering the package
	// was written under, or "" when none was recorded.
	SteeringVersion string

	// UpdatedAt is when a task last changed state, from progress.json, or ""
	// when none has. It is not in the PRD frontmatter: a task move writes the
	// progress file alone (format v3 §8.7).
	UpdatedAt string

	// PRD Markdown body (everything after the closing --- delimiter)
	PRDBody string

	// Dir is the directory path from which this spec was loaded. It is
	// set by LoadSpec and used by ValidateCrossFile to check that the
	// folder name's numeric prefix and snake_case suffix match SpecID
	// and SpecName. Empty when the spec was not loaded from disk.
	Dir string

	// JSON artifacts
	Requirements *RequirementsV3Json
	Tasks        *TasksV3Json
	// Progress is the state of every task, from progress.json, or nil when
	// the package has no progress file yet: every task is then pending.
	Progress *ProgressV3Json

	// Optional architecture document
	Architecture string

	// Has unexported fields.
}
    Spec represents a complete specification package with all artifacts. The PRD
    frontmatter fields are stored directly on the struct, while the PRD Markdown
    body is stored in PRDBody. The JSON artifacts are stored as pointers to the
    auto-generated types.

func CreateSpec(specID, specName string) *Spec
    CreateSpec creates a new draft Spec whose two contract artifacts carry a
    valid $schema, spec_id, spec_name and schema_version so that Save + LoadSpec
    round-trips. The artifact bodies are empty: a spec with no requirements and
    no tasks is *incomplete*, not schema-invalid, and Validate reports it as
    such (§10, bootstrap mode) until a generation run fills it in. The progress
    is empty too: every task is pending until a save writes progress.json.

    Validation of specID and specName is deferred to Spec.Validate.

func LoadSpec(dir string) (*Spec, error)
    LoadSpec reads all spec artifacts from a directory and returns a populated
    Spec struct. It reads prd.md, requirements.json, tasks.json, progress.json
    when it is there, and optionally architecture.md.

func LoadV2(dir string) (*Spec, error)
    LoadV2 reads the version 2 package in dir and returns the version 3
    package it converts to, in memory, by the rules of format v3 §13. Nothing
    is written. It returns a LoadError when the package is not version 2,
    when it cannot be read, or when a criterion is verified by no test or a path
    by no smoke test, which version 2 forbade and which has no deterministic
    conversion.

func (s *Spec) CompleteTaskStates(taskIDs []int) *ProgressV3Json
    CompleteTaskStates sets the named tasks to done, bypassing the state
    machine, and returns the progress to write. Unknown ids are skipped.

func (s *Spec) ComputeContractHash() (map[string]string, error)
    ComputeContractHash returns, for each of the ContractFiles, the hex SHA-256
    of the file's canonical encoding (the encoding Save writes) with every
    extension key left out. It hashes what the package holds, not the bytes on
    disk, so that another encoding of the same content and an x- key, which the
    format gives no meaning, leave the hash as it was.

    Returns a SaveError when an artifact cannot be encoded.

func (s *Spec) ComputeTraceability() TraceabilityMatrix
    ComputeTraceability derives the traceability matrix from the artifacts.
    Nothing is read from disk and nothing is stored, so the matrix cannot drift
    from the artifacts it describes (§8.5).

    Covered is ComputeCoverage's answer for the entity. Owned reports whether
    a task lists the criterion or its requirement; a path is owned by the
    integration task when the package has one.

func (s *Spec) ContractDrift() []string
    ContractDrift names, in the order of ContractFiles, each contract file
    that no longer hashes to the package's ContractHash, a file the hash has
    no entry for among them. A file that holds a key its schema does not allow
    differs too: the decode drops such a key, so the hash cannot see it, and an
    activated contract holds none. It is nil for a package without a contract
    hash, and for one whose files match it.

func (s *Spec) GetTask(id int) (*PlannedTask, bool)
    GetTask returns a copy of the planned task with the given id, the
    integration task included.

func (s *Spec) IntegrationTask() (PlannedTask, bool)
    IntegrationTask is the derived integration task of a full package: task N+1,
    depending on every task of the plan, touching what every task touches,
    with the steps of format v3 §8.4 computed from the paths, the contracts,
    the touches and the dependencies. It is false for a lite package and for a
    package with no task.

func (s *Spec) IntegrationTaskID() (int, bool)
    IntegrationTaskID is the id of the package's integration task: one past
    the highest task id of the plan. It is false for a lite package and for a
    package with no task (format v3 §8.4).

func (s *Spec) IsFinished() bool
    IsFinished reports whether nothing is left to implement in the package:
    its status ends its work (sealed, superseded or archived), or it is in this
    format version and none of its tasks is pending or in progress. The choice
    of the next package and specrun's label rules both read it.

func (s *Spec) IsLegacy() bool
    IsLegacy reports whether the package is in a format version other than the
    one this library reads. Such a package loads, but the v3 types read none of
    its progress and little of its plan. MigrateV2 converts a version 2 package.

func (s *Spec) IsLite() bool
    IsLite reports whether the package carries the lite profile: at most three
    requirements, no execution path, no smoke check and no integration task
    (format v3 §4.1). A package that names no profile is full.

func (s *Spec) IsReady(id int) bool
    IsReady reports whether the task with the given id can be started now:
    it is in the plan, it is pending, and everything it depends on is done.
    A task's dependencies are its depends_on when the field is present,
    where an empty list means none; when the field is absent, the task before
    it in plan order, and the first task then has none (format v3 §8.2). The
    integration task is ready when every task of the plan is done or dropped.
    A dependency the plan does not have, or one that is dropped, is not done.
    An unknown id and a nil receiver are not ready.

func (s *Spec) IsScaffold() bool
    IsScaffold reports whether the spec is still an empty scaffold:
    no requirements and no tasks. A scaffold is incomplete rather than invalid,
    which is what lets a tool save a spec before a generation run has produced
    its content.

func (s *Spec) NextTask() (*PlannedTask, bool)
    NextTask returns a copy of the task to work on now: the first in_progress
    task in plan order, else the first task for which IsReady is true. It
    returns nil and false when there is none, which a nil receiver and an empty
    plan are.

func (s *Spec) OpenTasks() []PlannedTask
    OpenTasks are the tasks of the plan that are pending or in progress,
    the derived integration task included, in plan order.

func (s *Spec) Owned(id int) []string
    Owned lists what the task with the given id answers for with evidence,
    in the order of requirements.json: for a task of the plan, every criterion
    its criteria name, a requirement id standing for all of that requirement's
    criteria; for the integration task, every execution path. It is nil for an
    id the plan does not have.

func (s *Spec) Plan() []PlannedTask
    Plan is every task of the package in id order: the tasks of tasks.json, each
    with kind implement, then the integration task when the package has one,
    each with its state from the progress. A nil receiver and a package with no
    tasks have an empty plan.

func (s *Spec) RenderCombined(opts ...RenderOption) string
    RenderCombined renders the whole spec as one Markdown document in the order
    of §11.1: PRD body, architecture if present, requirements, tasks.

    With WithMaxTokens(N) it applies progressive truncation:
      - level 0: full render
      - level 1: drop the architecture section
      - level 2: additionally render the checks and smoke checks in slim form

func (s *Spec) RenderIndividual(opts ...RenderOption) map[string]string
    RenderIndividual renders each artifact separately, keyed by "prd",
    "requirements", "tasks" and — only when present — "architecture". The same
    truncation levels as RenderCombined apply.

func (s *Spec) RenderIndividualScoped(taskID int, opts ...RenderOption) map[string]string
    RenderIndividualScoped renders the spec scoped to one task (§11.1): the PRD
    body without its Background and Requirements sections, which the criteria
    below restate, and the architecture unfiltered; for a task of the plan,
    the requirements that own the task's criteria in full and all others as
    one line each, the paths a shared check of those criteria names in full;
    for the integration task, every path in full with its smoke check and every
    requirement as one line, with the criteria that carry a contract; the task
    in full and all others as one line.

    Because rule C5 guarantees that every task lists its criteria, there is no
    inference: what a task owns is what it says. An unknown task ID falls back
    to the unscoped render.

func (s *Spec) RenderTasks() string
    RenderTasks renders the package's plan as Markdown: the test commands, the
    dependencies, every task of tasks.json and then the integration task (§8.4).
    No task state is rendered.

func (s *Spec) RenderedBytes() []byte
    RenderedBytes is what RenderedFileName must hold for the package:
    the RenderedHeader line, a blank line, and the whole render, with no scope
    and no budget. It is what every save writes, and what a program that writes
    a package's files itself writes to RenderedFileName. The same package always
    gives the same bytes, whatever its progress.

func (s *Spec) RequiresEvidence() bool
    RequiresEvidence reports whether the package's tasks close on evidence:
    it is active and was activated with a contract hash. A draft, and a package
    activated before the hash was recorded, do not (ADR 26).

func (s *Spec) ResetTaskStates(taskIDs []int) *ProgressV3Json
    ResetTaskStates sets the named tasks to pending, bypassing the state
    machine, and returns the progress to write. Unknown ids are skipped.

func (s *Spec) Save(dir string) error
    Save atomically writes all spec artifacts to the given directory,
    the progress file, and the package's render beside them as RenderedFileName.
    Each file is written to a temporary file first, then renamed to its
    final name. Returns a LifecycleError if the spec is sealed, superseded,
    or archived.

    For active specs with a stored IntentHash, Save recomputes the hash from
    the current PRD body and returns an IntentError if the ## Intent section has
    changed since activation (intent drift detection).

func (s *Spec) SaveProgress(dir string) error
    SaveProgress writes the package's progress file alone, atomically,
    and no other file: it is what a task move writes (format v3 §8.7). The
    progress holds every task of the plan and the integration task, in id order,
    with the states the Spec carries, and UpdatedAt. The lifecycle and intent
    guards of Save apply: a sealed package takes no task move either.

func (s *Spec) Supersede(supersedingSpecID, dir string) (*Spec, error)
    Supersede transitions a sealed spec to the superseded state, prepends a
    deprecation banner referencing the superseding spec ID to the PRD body,
    and persists the updated spec to disk. Returns a new Spec copy.

    Returns a LifecycleError if the spec is not in the sealed state.

func (s *Spec) TaskEvidence(id int) []EvidenceEntry
    TaskEvidence is a copy of the evidence progress.json holds for the task with
    the given id, sharing nothing with the package: for each criterion the task
    owns (for the integration task, each execution path), the tests that cover
    it and the runs speca recorded of them. It is nil for a task with none.

func (s *Spec) TaskState(id int) TaskState
    TaskState is the state of the task with the given id: its entry in the
    progress, or pending when it has none (format v3 §8.3). The id is not
    checked against the plan.

func (s *Spec) Transition(target, dir string) (*Spec, error)
    Transition updates the spec's status field to the target state, persists the
    updated spec to disk, and returns a new Spec copy with the updated status.
    The receiver is not modified.

    When transitioning from draft to active, ComputeIntentHash is called on the
    PRD body. If the body lacks a ## Intent section, an IntentError is returned
    and the spec is not persisted.

    Returns a LifecycleError if the transition is not allowed. Returns an
    IntentError if transitioning to active and the PRD body has no ## Intent
    section. Returns a SaveError if disk persistence fails.

func (s *Spec) TransitionTask(taskID int, target string) (*ProgressV3Json, error)
    TransitionTask moves one task to the target state and returns the progress
    to write; the receiver is not modified. It returns a LifecycleError when the
    task is not in the plan or the transition is not allowed by §8.1.

func (s *Spec) Validate() ValidationResult
    Validate runs schema validation followed by the cross-file rules and returns
    the combined result.

func (s *Spec) ValidateCrossFile() ValidationResult
    ValidateCrossFile runs the cross-file integrity rules C1 to C8 of §10.2 plus
    the warnings listed there. All rules are errors.

func (s *Spec) ValidateSchema() ValidationResult
    ValidateSchema validates the PRD frontmatter, the two contract artifacts
    and, when the package has one, the progress file against the bundled v3
    schemas. The EARS field constraints of §6.2.1 and the two forms of a check
    (§6.2.2) are expressed as conditionals inside requirements.v3.json, so there
    is no separate EARS check.

func (s *Spec) ValidateStructured() map[string]any
    ValidateStructured runs full validation and returns a structured map for CLI
    consumption with "valid", "errors" and, when non-empty, "warnings".

    Schema errors carry "artifact", "message" and optionally "path"; integrity
    errors carry "check" and "message".

func (s *Spec) WithTaskEvidence(id int, entries []EvidenceEntry) *ProgressV3Json
    WithTaskEvidence is the progress of the package with the evidence of the
    task with the given id replaced by entries (none when entries is empty),
    and every other task as it is: a new artifact, so the receiver's progress is
    not touched. An id the plan does not have changes nothing.

type SpecError struct {
	Msg string
}
    SpecError is the base error type for all afspec library errors. All specific
    error types wrap SpecError such that errors.As(err, &SpecError{}) returns
    true for any afspec error.

func (e *SpecError) Error() string

type SpecMeta struct {
	SpecID   string
	SpecName string
	Status   string
	Dir      string
}
    SpecMeta is a lightweight struct containing metadata parsed from a spec's
    PRD frontmatter, used for discovery and landscape views.

func DiscoverSpecs(root string) ([]SpecMeta, error)
    DiscoverSpecs scans the root directory for subdirectories matching the
    NN_snake_case pattern, parses the PRD frontmatter of each, and returns a
    slice of SpecMeta entries with SpecID, SpecName, Status, and Dir fields
    populated.

    If a subdirectory matches the pattern but its prd.md is missing or
    malformed, the entry is skipped and the error is collected. If the root
    directory does not exist or is not readable, a LoadError is returned.

func LoadSpecLandscape(root string, includeArchive bool, currentSpecID string) ([]SpecMeta, error)
    LoadSpecLandscape collects metadata for all specs for landscape views.
    It scans spec directories, optionally including the archive subdirectory,
    and excludes the currentSpecID entry from results.

    When includeArchive is true, archived specs from {root}/archive/ are
    included. When false, only non-archived spec directories are returned.

type ValidationEntry struct {
	Category string // "schema", "integrity" or "warning"
	Message  string
	Artifact string // the artifact file the issue was found in
	Path     string // JSON path (InstanceLocation) for schema errors
	Keyword  string // KeywordLocation for schema errors
	Check    string // rule name: "json_schema", "completeness", "C1".."C8", "scope_limit", "missing_contract", …
	EntityID string // the entity the entry is about
	Value    string // optional value context
}
    ValidationEntry is a single validation error or warning.

func ValidateArtifactSchema(artifact any, schemaName, artifactName string) []ValidationEntry
    ValidateArtifactSchema validates one already-decoded artifact against the
    named bundled schema. It is exported so the generation pipeline can check a
    model's tool input before it is turned into a Spec.

type ValidationError struct {
	Rule    string
	Message string
}
    ValidationError represents a single validation error from
    BootstrapSpec.Finalize. Rule identifies the type of check that failed (e.g.
    "bootstrap" for missing artifacts, or a schema/cross-file rule name).
    Message describes the failure.

type ValidationResult struct {
	Valid    bool
	Errors   []ValidationEntry
	Warnings []ValidationEntry
}
    ValidationResult holds the results of spec validation. Valid is true if and
    only if Errors is empty; warnings never block.

func CrossSpecFindings(specs []*Spec, spec *Spec) ValidationResult
    CrossSpecFindings runs the cross-spec rules over specs, the packages of
    one spec root, spec among them, and keeps the findings that concern spec.
    The graph is made of the dependencies the packages hold. The library tags
    an unknown dependency, a missing shared actor and the handoff rules with
    the package that decides them, so those are kept for it. The cycle names no
    package, and a package with no edge cannot be on one, so it is kept for any
    package with an edge. A warning tagged with the package's id is kept for it.

func StrictHandoffs(v ValidationResult) ValidationResult
    StrictHandoffs is v with each handoff_not_taken warning made an error,
    as a caller that will not start a package leaving a handoff untaken asks.

func ValidateCrossSpec(specs []*Spec, graph *DependencyGraph) ValidationResult
    ValidateCrossSpec checks the rules that span specs: every declared
    dependency exists, the dependency graph is acyclic, and each dependency
    edge between two packages that have execution paths is reflected by a shared
    actor in their paths (error).

    The v2 glossary comparison is gone with the glossary; the v1 external-API
    signature and return-contract comparisons were gone before it.

func ValidateGenerationStep(step GenerationStep, partial PartialSpec) ValidationResult
    ValidateGenerationStep runs, on the artifacts produced so far, the schema
    of the artifact just produced plus every cross-file rule of §10.2 that is
    decidable at that point (§12.2):

        after requirements  C1, C2 over requirements, C3, C6, C7
        after tasks         the above plus C2 over tasks, C4, C5

    A pipeline sends the returned errors back to the model for repair and does
    not write an artifact that still fails. Warnings are advisory.

    When the schema fails, only C6 and C7 run beside it: the reference rules
    would mostly report consequences of the same defect.

func ValidateGenerationStepComplete(step GenerationStep, partial PartialSpec) ValidationResult
    ValidateGenerationStepComplete is ValidateGenerationStep without that
    short-circuit: the cross-file rules run even when the schema fails,
    so a repair loop learns of every problem in one pass instead of one class
    per regenerated artifact. The schema errors come first, each with Category
    "schema"; a rule error may restate a consequence of one of them.

func ValidateInRoot(specsDir string, spec *Spec) (ValidationResult, error)
    ValidateInRoot is spec's own validation and the cross-spec rules that
    concern it, over the packages under specsDir that load (spec in place of
    the one at its directory), for a caller that needs the verdict without the
    commands that give it. It fails only when specsDir cannot be read.

type WaitingPackage struct {
	// Dir is the package directory, as the display function shows it.
	Dir string
	// SpecID is empty when the package did not load.
	SpecID string
	// WaitsOn is the spec ids of its dependencies that are not finished, in
	// the order its tasks.json names them; nil when it waits on nothing but
	// itself.
	WaitsOn []string
	// Reason says why, in words.
	Reason string
}
    WaitingPackage is a package under the spec root that is open but cannot
    start yet, or that cannot be judged: it does not load, or is in another
    format version.
