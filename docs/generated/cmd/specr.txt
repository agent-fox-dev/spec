Command specr renders a version 2 specification package as Markdown: the whole
package, or the package scoped to one of its tasks.

    specr [flags] <spec>

It takes exactly one input, a reference to a spec package, and writes exactly
one JSON object to stdout, whose result.markdown is the render. It reads the
package and changes nothing; the one file it can write is --markdown-file.

CONSTANTS

const (
	ReducedArchitecture = envelope.ReducedArchitecture
	ReducedTestDetail   = envelope.ReducedTestDetail
)
    What --max-tokens can drop, in the order it drops it.


VARIABLES

var Sections = envelope.Sections()
    Sections is the closed set of parts a render is made of, in the order the
    format renders them (§11.1). --section takes these names.


FUNCTIONS

func Main(argv []string, stdout, stderr io.Writer) int
    Main parses argv, renders, and writes one envelope to stdout. It returns the
    exit code.

    Two paths are for a person and print text instead: --version, and -h/--help
    or a bare invocation, which print the help to stderr. A bare invocation also
    writes a usage envelope when stdout is not a terminal, so a program piping
    stdout still gets one object to parse.


TYPES

type Result struct {
	envelope.RenderResult
}
    Result is specr's result. Its fields are the envelope package's
    RenderResult, which a program reading the output decodes into; the methods
    are what the shell asks of a result.

func (r *Result) Artifacts() []cli.Artifact
    Artifacts names the file --markdown-file wrote.

func (r *Result) Next() []cli.Next
    Next suggests rendering the next task that is not done: after a whole
    render, the first; after a task, the next one after it.

func (r *Result) Summary() string
    Summary is the envelope's one sentence.

type TaskInfo = envelope.TaskInfo
    TaskInfo is one task of the plan, by id, without its body.
